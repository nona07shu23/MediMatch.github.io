## 🚀 使い方

### 1. WEBサイト版（医療機関・医師共用）

#### ログイン方法

1. `web/login.html` をブラウザで開く
2. デモアカウントでログイン：
   - **医療機関用**: `facility@demo.medimatch.jp` / `demo1234`
   - **医師用**: `doctor@demo.medimatch.jp` / `demo1234`
3. ログイン後、ユーザータイプに応じて適切な画面に自動遷移

#### 医療機関向け画面

- **ダッシュボード** (`dashboard.html`)
  - 統計カード（公開中の求人、新着応募、選考中、マッチング成立）
  - 最近の応募一覧
  - 公開中の求人一覧

- **求人管理**
  - **求人一覧** (`job-list.html`) - 20件のデモ求人データ、タブ切り替え、フィルター機能
  - **求人作成** (`job-create.html`) - 新規求人の作成フォーム
  - **求人編集** (`job-edit.html`) - 既存求人の編集フォーム

- **医師検索・スカウト**
  - **医師検索** (`doctor-search.html`) - 20件のデモ医師データ、マッチ度スコア表示
  - **医師詳細** (`doctor-detail.html`) - 医師の詳細プロフィール
  - **スカウト一覧** (`scouts.html`) - 送信したスカウトの管理
  - **スカウト詳細** (`scout-detail.html`) - スカウトの詳細と返信状況
  - **スカウト作成** (`scout-create.html`) - スカウトメッセージの作成

- **応募管理**
  - **応募一覧** (`applications.html`) - 受信した応募の一覧
  - **応募詳細** (`application-detail.html`) - 応募者の詳細情報と選考状況

- **コミュニケーション**
  - **メッセージ一覧** (`messages.html`) - メッセージスレッド一覧
  - **メッセージスレッド** (`message-thread.html`) - 個別のメッセージやり取り

- **設定** (`settings.html`)
  - 施設情報の編集
  - アカウント設定
  - 通知設定

#### 医師向け画面

- **ホーム** (`doctor-home.html`)
  - ウェルカムカード
  - 統計カード（応募中、新着スカウト、未読メッセージ、保存した求人）
  - 新着スカウト一覧
  - おすすめ求人一覧

- **求人検索**
  - **求人検索** (`doctor-job-search.html`) - 20件のデモ求人データ、マッチ度スコア表示
  - **求人詳細** (`doctor-job-detail.html`) - 求人の詳細情報、応募ボタン

- **スカウト管理**
  - **スカウト一覧** (`doctor-scouts.html`) - 受信したスカウトの一覧

- **応募管理**
  - **応募一覧** (`doctor-applications.html`) - 自分の応募状況の確認
  - **応募詳細** (`doctor-application-detail.html`) - 応募の詳細と選考状況

- **コミュニケーション**
  - **メッセージ一覧** (`doctor-messages.html`) - メッセージスレッド一覧
  - **メッセージスレッド** (`doctor-message-thread.html`) - 個別のメッセージやり取り

- **勤務管理**
  - **カレンダー** (`doctor-calendar.html`) - 勤務予定の確認と管理

- **プロフィール**
  - **プロフィール表示** (`doctor-profile.html`) - 自分のプロフィール表示

- **設定** (`doctor-settings.html`)
  - アカウント設定
  - 通知設定
  - プライバシー設定

## 🎨 デザイン特徴

### ユニバーサルデザイン

- **アクセシビリティ対応**
  - 適切な色のコントラスト比
  - タッチターゲットサイズ確保（最小44px）
  - フォーカスインジケータ
  - スキップリンク
  - セマンティックHTML

- **カラーパレット**
  - プライマリカラー: ブルー系（#2563EB）
  - 色味を抑えた落ち着いたデザイン
  - グレースケールを効果的に活用

- **タイポグラフィ**
  - システムフォント使用
  - 明瞭な階層構造
  - 適切な行間・文字間隔

### レスポンシブデザイン

- **WEB版** (`web/`)
  - PC・タブレット対応（画面幅768px以上を想定）
  - サイドバーナビゲーション
  - グリッドレイアウト
  - 医療機関向け・医師向けで異なるナビゲーション構成

- **アプリ版** (`app/`)
  - モバイルファースト（最大幅480px）
  - スマートフォンサイズに最適化
  - ボトムナビゲーション
  - スワイプ操作を想定したUI
  - セーフエリア対応（viewport-fit=cover）

## 📊 デモデータ

### 求人データ（20件）

- 様々な診療科（内科、外科、整形外科、小児科、産婦人科など）
- 雇用形態（常勤、非常勤、スポット）
- 地域（東京都、神奈川県、千葉県、大阪府など）
- 給与レンジ（年収1,100万円〜3,000万円）

### 医師データ（20件）

- 様々な専門科
- 経験年数5年〜25年
- 資格・専門医情報
- スキル・手技情報
- 症例数データ
- 希望勤務地・雇用形態

## 🔧 技術スタック

- **HTML5**: セマンティックマークアップ
- **CSS3**: Flexbox、Grid、CSS Variables
- **JavaScript**: Vanilla JS（フレームワーク不使用）
- **デザインシステム**: カスタムCSSフレームワーク

## 📝 注意事項

- このモックアップは静的HTMLであり、実際のバックエンド機能は実装されていません
- データはすべてJavaScriptのオブジェクトとして定義されたデモデータです（`common/demo-data.js`）
- ログイン機能は`sessionStorage`を使用した簡易実装です
- フォーム送信やデータ更新は実際には保存されません（画面遷移のみ）
- 一部のインタラクティブ機能（ファイルアップロード、決済処理等）はモックアップのため動作しません
