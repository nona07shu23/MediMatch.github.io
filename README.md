# MediMatch HTMLモックアップ

医療人材マッチングプラットフォーム「MediMatch」のHTMLモックアップです。

## 📁 フォルダ構成

```
HTMLモックアップ/
├── common/
│   ├── common.css          # 共通スタイル（ユニバーサルデザイン、ブルー基調）
│   └── demo-data.js        # デモデータ（20件の求人、医師情報）
│
├── web版/                   # WEBサイト（医療機関・医師共用）
│   ├── web-style.css       # WEB専用スタイル
│   ├── login.html          # ログイン画面（両方のユーザータイプ対応）
│   │
│   ├── 【医療機関向け】
│   ├── dashboard.html      # 医療機関用ダッシュボード
│   ├── job-list.html       # 求人一覧・管理
│   └── doctor-search.html  # 医師検索
│   │
│   └── 【医師向け】
│       ├── doctor-home.html        # 医師用ホーム
│       ├── doctor-job-search.html  # 求人検索
│       └── doctor-job-detail.html  # 求人詳細
│
└── app版-スマホ専用/         # 医師向けスマホアプリ
    ├── app-style.css       # アプリ専用スタイル
    ├── login.html          # ログイン画面
    ├── home.html           # ホーム画面
    ├── job-search.html     # 求人検索
    └── job-detail.html     # 求人詳細
```

## 🚀 使い方

### 1. WEBサイト版（医療機関・医師共用）

#### ログイン方法

1. `web版/login.html` をブラウザで開く
2. デモアカウントでログイン：
   - **医療機関用**: `facility@demo.medimatch.jp` / `demo1234`
   - **医師用**: `doctor@demo.medimatch.jp` / `demo1234`
3. ログイン後、ユーザータイプに応じて適切な画面に自動遷移

#### 医療機関向け画面

- **ダッシュボード** (`dashboard.html`)
  - 統計カード（公開中の求人、新着応募、選考中、マッチング成立）
  - 最近の応募一覧
  - 公開中の求人一覧

- **求人一覧** (`job-list.html`)
  - 20件のデモ求人データを表示
  - タブ切り替え（すべて、公開中、下書き、募集終了）
  - フィルター機能（診療科、雇用形態、キーワード検索）

- **医師検索** (`doctor-search.html`)
  - 20件のデモ医師データを表示
  - 詳細な医師情報（資格、スキル、経験年数、症例数）
  - マッチ度スコア表示
  - スカウト送信機能

#### 医師向け画面

- **ホーム** (`doctor-home.html`)
  - ウェルカムカード
  - 統計カード（応募中、新着スカウト、未読メッセージ、保存した求人）
  - 新着スカウト一覧
  - おすすめ求人一覧

- **求人検索** (`doctor-job-search.html`)
  - 20件のデモ求人データを表示
  - キーワード検索、詳細フィルター
  - マッチ度スコア表示（80-100%）
  - カード型レイアウト

- **求人詳細** (`doctor-job-detail.html`)
  - 求人の詳細情報
  - 施設情報、募集要項、待遇・福利厚生
  - 応募ボタン

### 2. スマホアプリ版（医師専用）

1. `app版-スマホ専用/login.html` をブラウザで開く
2. デモアカウントでログイン：
   - **メールアドレス**: `doctor@demo.medimatch.jp`
   - **パスワード**: `demo1234`
3. ホーム、求人検索、求人詳細などの画面を確認

#### 主な画面

- **ログイン画面** (`login.html`)
  - モバイル最適化デザイン
  - デモアカウント情報をクリックして入力欄にコピー可能

- **ホーム画面** (`home.html`)
  - プロフィールサマリー
  - 今月の活動統計（応募中、スカウト）
  - 新着スカウト一覧
  - おすすめ求人
  - クイックアクションボタン
  - ボトムナビゲーション

- **求人検索** (`job-search.html`)
  - 20件のデモ求人データを表示
  - キーワード検索
  - フィルターチップ（雇用形態、診療科）
  - 詳細フィルターモーダル
  - マッチ度スコア表示

- **求人詳細** (`job-detail.html`)
  - 求人の詳細情報
  - 施設情報
  - 募集要項
  - 待遇・福利厚生
  - お気に入り機能
  - シェア機能
  - 応募ボタン

## 🎨 デザイン特徴

### ユニバーサルデザイン

- **アクセシビリティ対応**
  - 適切な色のコントラスト比
  - タッチターゲットサイズ確保（最小44px）
  - フォーカスインジケータ
  - スキップリンク
  - セマンティックHTML

- **カラーパレット**
  - プライマリカラー: ブルー系（#2563EB）
  - 色味を抑えた落ち着いたデザイン
  - グレースケールを効果的に活用

- **タイポグラフィ**
  - システムフォント使用
  - 明瞭な階層構造
  - 適切な行間・文字間隔

### レスポンシブデザイン

- **WEB版**
  - PC・タブレット対応
  - サイドバーナビゲーション
  - グリッドレイアウト

- **アプリ版**
  - モバイルファースト
  - 最大幅480px（スマートフォンサイズ）
  - ボトムナビゲーション
  - スワイプ操作を想定したUI

## 📊 デモデータ

### 求人データ（20件）

- 様々な診療科（内科、外科、整形外科、小児科、産婦人科など）
- 雇用形態（常勤、非常勤、スポット）
- 地域（東京都、神奈川県、千葉県、大阪府など）
- 給与レンジ（年収1,100万円〜3,000万円）

### 医師データ（20件）

- 様々な専門科
- 経験年数5年〜25年
- 資格・専門医情報
- スキル・手技情報
- 症例数データ
- 希望勤務地・雇用形態

## 🔧 技術スタック

- **HTML5**: セマンティックマークアップ
- **CSS3**: Flexbox、Grid、CSS Variables
- **JavaScript**: Vanilla JS（フレームワーク不使用）
- **デザインシステム**: カスタムCSSフレームワーク

## 📝 注意事項

- このモックアップは静的HTMLであり、実際のバックエンド機能は実装されていません
- データはすべてJavaScriptのオブジェクトとして定義されたデモデータです
- ログイン機能は`sessionStorage`を使用した簡易実装です
- 一部の画面（スカウト管理、メッセージ、プロフィール等）は未実装です
